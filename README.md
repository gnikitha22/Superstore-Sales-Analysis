# Superstore Sales Analysis

## Project Overview

This project analyzes Superstore sales data to understand sales performance, customer segments, product performance, regional sales, and shipping patterns using Python and Pandas.

## Dataset

The dataset contains Superstore sales records with information about orders, customers, products, sales, regions, categories, and shipping.

- Rows: 9,800
- Columns: 18
- Source: Kaggle

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- VS Code
- Git & GitHub

## Analysis Performed

- Data cleaning and preprocessing
- Missing value analysis
- Duplicate record checking
- Sales analysis by category, region, and segment
- Yearly and monthly sales analysis
- Top product analysis
- Shipping time analysis

## Key Insights

- Technology generated the highest sales among the three categories.
- The West region recorded the highest total sales.
- 2018 had the highest yearly sales.
- November recorded the highest monthly sales.
- Canon imageCLASS 2200 Advanced Copier was the top product by total sales.
- Consumer was the highest-selling customer segment.
- 4 days was the most common shipping duration.

4. Select a Python kernel.
5. Run the notebook cells to reproduce the analysis.

## Conclusion

This analysis provides an overview of Superstore sales performance across different categories, regions, customer segments, products, time periods, and shipping durations. The project demonstrates how Python, Pandas, and Matplotlib can be used to clean, analyze, and visualize real-world sales data.
